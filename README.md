# P-O-X Complete Knowledge Base & Strategy Guide

A self-contained, searchable preservation guide for Hasbro P-O-X.

## Included

- Complete 001–189 part index and 63 ability groups
- Original surviving part badges cropped to the useful 53×40 display area
- Official origin lore and a detailed P-O-X glossary
- W.A.D. construction, damage planning, body-building methodology, classic combinations, and the community “Cloning” method
- Classified-part and promotional-PCU research with uncertainty labels
- Maps for 16 of the 17 Genome Arenas, including selectable alternate maps for stages with multiple surviving reconstructions
- Structured tables for documenting every enemy Infector and Overspore
- Hardware, RF, species-jumper, playthrough, and Biota Virus research notes

## Run locally

Open `index.html` in any modern browser.

## View Online

The file is hosted publicly at https://avideogamestore.com/pox/.

## Collaborate

Clone or fork the repository, edit `index.html`, verify changes in desktop and mobile layouts, and submit a pull request. Contributions are especially valuable for Arena 3 mapping, enemy/Overspore statistics, classified-part verification, promotional-unit history, and reproducible hardware research.


## Arena maps

The guide embeds 21 surviving map images covering 16 of the 17 Genome Arenas. Alternate maps are retained as selectable thumbnails. Arena 3 remains open for preservation and documentation.
