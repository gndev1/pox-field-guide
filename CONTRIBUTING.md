# Contributing

This guide is intended to improve through documented community research.

## Good contributions

- A missing or alternate Genome Arena map
- Exact enemy or Overspore location, species, Head/Body/Tail parts, color codes, HP, W.A.D., behavior, and reward
- Clear photographs or video timestamps showing the complete PCU screen before and after an event
- Corrections to part text or index values
- Reproducible RF, jumper, classified-part, promotional-unit, cloning, or Biota Virus experiments

## Evidence labels

Describe each claim as one of the following:

- **Official** — directly shown in surviving Hasbro material
- **Observed** — reproduced on retail hardware
- **Community report** — preserved period claim not yet independently reproduced
- **Patent candidate** — described in patent material but not confirmed in retail firmware
- **Unknown** — open research field

## Pull requests

Keep the guide self-contained. Embed small images as data URIs, preserve all existing map variants, do not remove uncertainty labels, and test search, filters, map switching, the lightbox, and mobile layout before submitting.
